# バンドナイフ張力測定アプリ

スマホのマイクでバンドナイフ（帯刃）を叩いた音の固有振動数を検出し、張力 T = 4·m·S²·f² を算出するAndroidアプリと、測定結果を閲覧するWindowsソフトです。

## 成果物

| ファイル | 説明 |
|---------|------|
| `バンドナイフ張力計.apk` | Androidアプリ（インストール用） |
| `バンドナイフ張力ビューア.exe` | Windows閲覧ソフト（ランタイム不要） |
| `drive-upload.gs` | Googleドライブ連携用 Apps Script |
| `android/` | Androidソースコード |
| `windows-viewer/` | Windowsビューアソースコード |

## Androidアプリのインストール

1. `バンドナイフ張力計.apk` をスマホにコピー
2. 設定 → セキュリティ → 「提供元不明のアプリ」を許可
3. APKファイルをタップしてインストール
4. 初回起動時にマイクの使用を許可

## 使い方

### シンプルモード（既定）
1. **設備を選ぶ** — 登録済み設備をタップ
2. **測定する** — 刃の中央を5回軽く叩く
3. **結果** — 張力と合否を確認し「記録して終了」

### アドバンスモード
シンプルモードと同じ導線ですが、結果画面にヒストグラム・信頼区間・統計量を表示します。

### 詳細モード
設備の登録・編集、単発/連続測定、履歴管理、設定、ヘルプなど全機能にアクセスできます。画面右上の「モード切替」から変更できます。

## 測定のコツ

- **叩く道具**: プラスチックの柄や指の腹（金属はNG）
- **叩く位置**: スパン（自由振動区間）の中央
- **叩く強さ**: 軽くポンと弾く程度
- **マイク**: 刃から1〜2cm離して保持
- **安全**: 必ず機械を停止してから測定

## Googleドライブ連携のセットアップ

1. https://script.google.com で新規プロジェクトを作成
2. `drive-upload.gs` の内容を貼り付け
3. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
   - アクセス: 全員 / 実行ユーザー: 自分
4. デプロイURLをアプリの「設定」→「Drive アップロードURL」に入力
5. 「自動アップロード」をONにする

初回実行時にマイドライブに **「バンドナイフ張力測定」** フォルダが自動作成され、測定記録がスプレッドシートと `records.csv` に追記されます。

## Windows閲覧ソフト

1. PCに Google Drive for Desktop をインストールし、専用フォルダを同期
2. `バンドナイフ張力ビューア.exe` をダブルクリックで起動
3. データフォルダが自動検出されない場合は「フォルダ選択」で指定
   - 例: `D:\マイドライブ\バンドナイフ張力測定`

機能: ダッシュボード（最新値一覧）、推移グラフ、履歴テーブル、CSVエクスポート

## 設備プリセットの登録

詳細モード → 設備タブ → 「設備を追加」

| 項目 | 説明 | 例 |
|------|------|-----|
| 設備名 | 識別名 | ペフ用スライサー1号 |
| 幅・厚み | m自動計算用 | 50mm × 0.8mm |
| スパン長 S | 自由振動区間 (m) | 0.85 |
| 標準値 | 目標張力 (N) | 160 |
| 規格範囲 | 合否判定の上下限 (N) | 150〜180 |

## ビルド方法（開発者向け）

### Android
```bash
cd android
gradlew assembleRelease
```

### Windows
```bash
cd windows-viewer
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## 対応OS

- Android 8.0 (API 26) 以上
- Windows 10/11 (x64)
