# バンドナイフ張力測定アプリ

スマホのマイクでバンドナイフ（帯刃）を叩いた音の固有振動数を検出し、張力を算出するAndroidアプリと、測定結果を閲覧するWindowsソフトです。張力は張力＋曲げモデル（オイラー・ベルヌーイ梁）で計算し、幅・厚み・材種（ヤング率・密度）を反映します。

## 成果物

| ファイル | 説明 |
|---------|------|
| `バンドナイフ張力計.apk` | Androidアプリ（インストール用） |
| `バンドナイフ張力ビューア.exe` | Windows閲覧ソフト（ランタイム不要） |
| `docs/manual/MANUAL.md` | **操作マニュアル（スクリーンショット付き）** |
| `docs/manual/MANUAL.pdf` | 操作マニュアル PDF 版（印刷・配布用） |
| `drive-upload.gs` | Googleドライブ連携用 Apps Script |
| `android/` | Androidソースコード |
| `windows-viewer/` | Windowsビューアソースコード |

## Androidアプリのインストール

1. `バンドナイフ張力計.apk` をスマホにコピー
2. 設定 → セキュリティ → 「提供元不明のアプリ」を許可
3. APKファイルをタップしてインストール
4. 初回起動時にマイクの使用を許可

## 使い方

### シンプルモード（既定）
1. **設備を選ぶ** — 登録済み設備をタップ
2. **測定する** — 刃の中央を5回軽く叩く
3. **結果** — 張力と合否を確認し「記録して終了」

### アドバンスモード
シンプルモードと同じ導線ですが、結果画面にヒストグラム・信頼区間・統計量を表示します。

### 詳細モード
設備の登録・編集、単発/連続測定、履歴管理、設定、ヘルプなど全機能にアクセスできます。画面右上の「モード切替」から変更できます。

## 測定のコツ

- **叩く道具**: プラスチックの柄や指の腹（金属はNG）
- **叩く位置**: スパン（自由振動区間）の中央
- **叩く強さ**: 軽くポンと弾く程度
- **マイク**: 刃から1〜2cm離して保持
- **安全**: 必ず機械を停止してから測定

## Googleドライブ連携のセットアップ

1. https://script.google.com で新規プロジェクトを作成
2. リポジトリ直下の `drive-upload.gs` の内容を貼り付け（スクリプトはこの 1 本だけです）
3. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
   - アクセス: 全員 / 実行ユーザー: 自分
4. デプロイURLをアプリの「設定」→「Drive アップロードURL」に入力
5. 「自動アップロード」をONにする

初回実行時にマイドライブに **「バンドナイフ張力測定」** フォルダが自動作成され、測定記録がスプレッドシートと `records.csv` に追記されます。

> 既存の GAS プロジェクトを使っている場合も、設備マスターの共有と使用者管理を使うには `drive-upload.gs` を貼り直して**再デプロイ**してください。古いスクリプトのままだと、アプリ側で「ドライブのスクリプトが最新ではありません」と表示されます。

### 登録キーで使用者登録を絞る（推奨）

ウェブアプリの URL は APK から取り出せるため、既定のままだと URL を知っている人は誰でも使用者を登録でき、設備マスターを書き換えられます。これを防ぐには Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」に次を追加してください。

| プロパティ | 値 |
|-----------|-----|
| `REGISTRATION_KEY` | 管理者だけが知る任意の文字列 |

設定すると、アプリの使用者登録画面で同じ文字列を「登録キー」に入力しない限り登録できなくなります。**未設定のときは登録キーなしで登録できます**（小規模・初期構築向け）。本番運用では必ず設定してください。登録済みの使用者のサインインには影響しません。

## 使用者の登録（名前とパスワード）

誰が設備設定を変えたのかを残すため、設備の追加・編集にはサインインが必要です。

- **初回起動時**に名前とパスワードを設定します。既に登録済みの名前があれば「登録済みの使用者」からサインインしてください
- パスワードは端末内で鍵に変換され、暗号化して保存されます。**2 回目以降の入力は不要**です
- 名前とパスワードは「その他」→「使用者」→「名前・パスワードを変更」からいつでも変えられます
- 使用者の一覧は GAS 側の `users.json` とスプレッドシートの「使用者」シートで管理します。パスワードそのものは保存されず、端末で変換した値をさらにハッシュ化した結果だけが残ります

> 名前を変更すると、同じ名前でサインインしていた他の端末は再サインインが必要になります。
> 端末を初期化したりアプリを入れ直したりすると保存済みの資格情報は消えるので、同じ名前とパスワードでサインインし直してください（バックアップからは復元されません）。

## 設備マスターの共有と測定のロック

設備の設定（規格値・寸法・Hz 管理の設定）は Google ドライブで一元管理します。**ドライブの設備マスターに載っていない設備では測定できません。**

```
[管理者の端末]                    [作業者の端末]
 設備を登録・編集                  起動時に自動で取り込み
     │                                  ▲
     │「ドライブへ登録」                  │
     ▼                                  │
[Google ドライブ]  バンドナイフ張力測定/equipment.json
                   ＋スプレッドシートの「設備マスター」シート
```

### 運用手順

1. 管理者の端末で設備を登録・編集する（設備の追加・編集には使用者のサインインが必要です）
2. 詳細モード →「その他」→「設備マスターの共有」→ **「ドライブへ登録」**
   - ドライブの設備マスターは、その端末の設備一覧で置き換わります
   - 既存の設備が消える内容のときは、消える設備名を出して確認を求めます
   - 他の人が先に更新していた場合は登録を中止します。「今すぐ確認」で取り込み直してからやり直してください
3. 各作業者の端末はアプリ起動時に自動で取り込みます。手動で取り込む場合は同じ画面の **「今すぐ確認」**

### 誰がいつ更新したかを見る

ドライブへ登録するたびに世代（第 N 版）が 1 つ進み、更新者名・日時・変更概要が記録されます。

- アプリ: 「その他」→「設備マスターの更新履歴」→「履歴を読み込む」
- ドライブ: `equipment-history.json` とスプレッドシートの「設備マスター履歴」シート

### 測定が止まる条件

| 状態 | 画面の表示 | 測定 |
|------|-----------|------|
| 設備がドライブ未登録 | 設備カードに「ドライブ未登録」バッジ、選択不可 | その設備のみ不可 |
| 接続確認から 5 日以上 | 「あと N 日で測定できなくなります」 | 可 |
| 接続確認から 7 日以上 | 「測定できません」＋「今すぐ確認」 | すべて不可 |

古い規格値のまま合否を出して不良を良品と判定する事故を防ぐための制限です。**7 日ごとに電波の届く場所で「今すぐ確認」を通す運用が前提**になります。端末で設備を編集した場合も、ドライブへ登録し直すまでその設備は測定に使えません。

### ローカルモード（GAS が長期間使えないとき）

ドライブや GAS に長期間つながらない場合、**詳細モード → その他 → ローカルモード** から端末だけで測定を続けられます。

| 項目 | ローカルモード中の動作 |
|------|----------------------|
| 測定 | 端末内の設備設定で測定可能（ドライブ未登録・7日ルールは適用しない） |
| 記録 | 端末の履歴にのみ保存。「端末のみ」と表示され、**ドライブへは送らない** |
| ドライブ連携に戻した後 | ローカルモード中の記録は**引き続き端末のみ**（自動アップロードしない） |
| 設備の変更 | 端末専用の使用者（名前＋パスワード）で変更可能 |
| 切り替え | 保存済みパスワードの入力が必要 |

> ローカルモードは規格の一元管理を外れるため、GAS が復旧したらドライブ連携モードへ戻し、「今すぐ確認」で設備マスターを取り込む運用を推奨します。

## Windows閲覧ソフト

1. PCに Google Drive for Desktop をインストールし、専用フォルダを同期
2. `バンドナイフ張力ビューア.exe` をダブルクリックで起動
3. データフォルダが自動検出されない場合は「フォルダ選択」で指定
   - 例: `D:\マイドライブ\バンドナイフ張力測定`

機能: ダッシュボード（最新値一覧）、推移グラフ、履歴テーブル、CSVエクスポート

## 設備プリセットの登録

詳細モード → 設備タブ → 「設備を追加」

| 項目 | 説明 | 例 |
|------|------|-----|
| 設備名 | 識別名 | ペフ用スライサー1号 |
| 幅・厚み | m自動計算用 | 86mm × 1.25mm |
| スパン長 S | 自由振動区間 (m) | 1.0 |
| 標準値 | 目標張力 (N) | 160 |
| 規格範囲 | 合否判定の上下限 (N) | 150〜180 |

## ビルド方法（開発者向け）

### Android
```bash
cd android
gradlew assembleRelease
```

### Windows
```bash
cd windows-viewer
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## 対応OS

- Android 8.0 (API 26) 以上
- Windows 10/11 (x64)
