# drive-upload.gs ドキュメント

バンドナイフ張力測定アプリの測定結果を、Google ドライブ上のスプレッドシートと CSV に自動保存するための **Google Apps Script（GAS）** です。

Android アプリが HTTP POST で JSON データを送信すると、GAS が受け取り、マイドライブ内の専用フォルダに記録を追記します。PC 側の Windows ビューアは、同期された `records.csv` を読み込んでグラフや一覧を表示します。

---

## 全体の流れ

```
[Android アプリ]
    │ 測定記録を保存
    │ 自動アップロード ON の場合
    ▼
[HTTP POST (JSON)]
    │
    ▼
[drive-upload.gs（ウェブアプリ）]
    │ ① フォルダ取得/作成
    │ ② スプレッドシートへ1行追記
    │ ③ records.csv へ1行追記
    ▼
[Google ドライブ]
  バンドナイフ張力測定/
    ├── 張力記録（スプレッドシート）
    └── records.csv
    │
    │ Google Drive for Desktop で同期
    ▼
[Windows ビューア]
  records.csv を読み込み表示
```

## ファイルの役割

| 定数 | 値 | 説明 |
|------|-----|------|
| `FOLDER_NAME` | `バンドナイフ張力測定` | マイドライブに作成されるフォルダ名 |
| `SPREADSHEET_NAME` | `張力記録` | スプレッドシートのファイル名 |
| `CSV_NAME` | `records.csv` | CSV ファイル名（Windows ビューアが参照） |

## 関数の動作

### `doPost(e)` — メインの受信処理

Android アプリから送られた JSON を処理するエントリポイントです。

1. リクエストボディを JSON としてパース
2. `getOrCreateFolder()` で保存先フォルダを確保
3. `getOrCreateSpreadsheet()` でスプレッドシートを確保
4. `appendToSheet()` でスプレッドシートに1行追加
5. `appendToCsv()` で CSV に1行追加
6. 成功時は `{ "status": "ok" }`、失敗時は `{ "status": "error", "message": "..." }` を返却

### `getOrCreateFolder()`

マイドライブ直下に `バンドナイフ張力測定` フォルダを探し、なければ新規作成します。

### `getOrCreateSpreadsheet(folder)`

フォルダ内に `張力記録` スプレッドシートを探し、なければ新規作成します。

初回作成時の処理:

- スプレッドシートを作成し、指定フォルダへ移動（マイドライブ直下からは削除）
- シート名を `全記録` に変更
- ヘッダー行を追加

| 列 | 内容 |
|----|------|
| 日時 | `Asia/Tokyo` タイムゾーンで `yyyy/MM/dd HH:mm:ss` 形式 |
| 設備名 | 測定対象の設備名 |
| 周波数(Hz) | 検出した固有振動数 |
| 張力(N) | 算出した張力 |
| 合否 | `OK` または `要調整` |
| n数 | サンプル数 |
| 標準偏差 | 測定値の標準偏差 |
| CI下限 | 95% 信頼区間の下限 |
| CI上限 | 95% 信頼区間の上限 |
| コメント | 任意コメント |

### `appendToSheet(ss, data)`

スプレッドシートの `全記録` シート末尾に、受信データを1行追記します。`passed` が `true` のとき合否列は `OK`、`false` のとき `要調整` になります。

### `appendToCsv(folder, data)`

フォルダ内の `records.csv` に1行追記します。ファイルが存在しない場合はヘッダー行付きで新規作成します。

コメント欄にカンマやダブルクォートが含まれる場合は、CSV 形式に合わせてエスケープされます。

### `doGet()`

ブラウザで URL に直接アクセスしたときの応答です。動作確認用に、API の説明テキストを返します。データの保存は行いません。

## セットアップ手順

### 1. Google Apps Script プロジェクトを作成

1. [Google Apps Script](https://script.google.com) にアクセス
2. **新しいプロジェクト** を作成
3. プロジェクト名を分かりやすい名前に変更（例: `バンドナイフ張力測定アップロード`）
4. エディタの `コード.gs` の内容をすべて削除し、リポジトリの `drive-upload.gs` の内容を貼り付け
5. **保存**（Ctrl+S）

### 2. 初回の権限承認（推奨）

デプロイ前に、スクリプトが Google ドライブへアクセスできることを確認します。

1. エディタ上部の関数選択で任意の関数（例: `doGet`）を選択
2. **実行** をクリック
3. 初回は **権限の確認** が表示されるので、自分の Google アカウントで承認
4. 「このアプリは Google で確認されていません」と出た場合は **詳細** → **（プロジェクト名）に移動** で続行

必要な権限:

- Google ドライブ（フォルダ・ファイルの作成・更新）
- Google スプレッドシート（シートへの追記）

### 3. ウェブアプリとしてデプロイ

1. 右上の **デプロイ** → **新しいデプロイ**
2. 種類の歯車アイコン → **ウェブアプリ** を選択
3. 次の設定を行う

| 項目 | 設定値 |
|------|--------|
| 説明 | 任意（例: `v1`） |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** |

4. **デプロイ** をクリック
5. 表示された **ウェブアプリの URL** をコピー（末尾が `/exec` の URL）

> **重要:** コードを変更したあとは、**デプロイを管理** → **新バージョンを編集** → **デプロイ** で再デプロイしないと、本番 URL に変更が反映されません。

## Android アプリ側の設定

1. アプリを **詳細モード** で起動
2. **設定** 画面を開く
3. **Drive アップロードURL** に、デプロイで取得したウェブアプリ URL を貼り付け
4. **自動アップロード** を ON にする
5. **テスト送信** を押して接続を確認

### テスト送信の内容

テスト送信では、次のサンプルデータが1件 POST されます。

```json
{
  "timestamp": 1700000000000,
  "equipmentName": "テスト",
  "frequencyHz": 85.0,
  "tensionN": 160.0,
  "passed": true,
  "sampleCount": 1,
  "stdDev": 0.0,
  "ci95Lower": 160.0,
  "ci95Upper": 160.0,
  "comment": "テスト送信"
}
```

成功すると、Google ドライブの `バンドナイフ張力測定` フォルダにスプレッドシートと CSV が作成（または更新）されます。

### 通常の測定時の動作

- 測定記録を保存するたびに、自動アップロードが ON なら送信キューに追加されます
- 送信に成功したデータはキューから削除されます
- ネットワークエラー時はキューに残り、**再送** ボタンまたはアプリ再起動時に再試行されます
- 設定画面の **未送信** 件数で、送信待ちの件数を確認できます

## API 仕様

### POST（データ送信）

| 項目 | 内容 |
|------|------|
| URL | デプロイ時に発行されたウェブアプリ URL |
| メソッド | `POST` |
| Content-Type | `application/json` |
| ボディ | 下記 JSON |

#### リクエスト JSON

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `timestamp` | number | ○ | Unix 時刻（ミリ秒） |
| `equipmentName` | string | ○ | 設備名 |
| `frequencyHz` | number | ○ | 周波数 (Hz) |
| `tensionN` | number | ○ | 張力 (N) |
| `passed` | boolean | ○ | 合否（`true` = OK） |
| `sampleCount` | number | △ | サンプル数（省略時: 1） |
| `stdDev` | number | △ | 標準偏差（省略時: 0） |
| `ci95Lower` | number | △ | 信頼区間下限（省略時: 0） |
| `ci95Upper` | number | △ | 信頼区間上限（省略時: 0） |
| `comment` | string | △ | コメント（省略時: 空文字） |

#### レスポンス

成功（HTTP 200）:

```json
{ "status": "ok" }
```

失敗（HTTP 200、ボディにエラー情報）:

```json
{ "status": "error", "message": "エラーの詳細" }
```

> GAS のウェブアプリは、スクリプト内でエラーを catch した場合でも HTTP ステータス 200 で JSON を返すことがあります。Android アプリ側は HTTP ステータスコードの成功/失敗で判定しています。

### GET（動作確認）

ブラウザでウェブアプリ URL を開くと、次のテキストが表示されます。

```
バンドナイフ張力測定 API - POSTでデータを送信してください
```

## Google ドライブ上に作成されるファイル

初回のデータ受信時に、次の構成が自動作成されます。

```
マイドライブ/
└── バンドナイフ張力測定/
    ├── 張力記録          ← Google スプレッドシート（人が見やすい形式）
    └── records.csv       ← CSV（Windows ビューアが読み込む）
```

### records.csv の形式

```csv
timestamp,equipmentName,frequencyHz,tensionN,passed,sampleCount,stdDev,ci95Lower,ci95Upper,comment
1700000000000,ペフ用スライサー1号,85.2,162.5,true,5,1.2,160.1,164.9,""
```

## Windows ビューアとの連携

1. PC に [Google Drive for Desktop](https://www.google.com/drive/download/) をインストール
2. `バンドナイフ張力測定` フォルダが PC 上に同期されることを確認
   - 例: `C:\Users\<ユーザー名>\マイドライブ\バンドナイフ張力測定`
3. `バンドナイフ張力ビューア.exe` を起動
4. フォルダが自動検出されない場合は **フォルダ選択** で上記パスを指定

ビューアは `records.csv` を読み込み、ダッシュボード・推移グラフ・履歴テーブルを表示します。スプレッドシートは人間がブラウザやスマホで直接確認する用途向けです。

## トラブルシューティング

| 症状 | 確認・対処 |
|------|-----------|
| テスト送信してもドライブにファイルがない | URL が `/exec` で終わっているか確認。GAS の実行ログ（**実行数** メニュー）でエラーを確認 |
| 「権限がありません」系のエラー | GAS のデプロイ設定で「実行ユーザー: 自分」になっているか確認。初回の権限承認を完了する |
| テストは成功するが測定データが上がらない | アプリの **自動アップロード** が ON か確認。**未送信** 件数を確認し、必要なら **再送** |
| コードを変更したが動作が変わらない | GAS で **新バージョン** として再デプロイしたか確認 |
| Windows ビューアにデータが出ない | Drive for Desktop の同期完了を待つ。`records.csv` がフォルダ内にあるか確認 |
| 同じ名前のフォルダが複数ある | GAS は名前が一致する最初のフォルダを使用します。不要な同名フォルダは整理してください |

### curl での手動テスト

PC のターミナルから接続確認する場合:

```bash
curl -X POST "https://script.google.com/macros/s/XXXXXXXX/exec" \
  -H "Content-Type: application/json" \
  -d "{\"timestamp\":1700000000000,\"equipmentName\":\"手動テスト\",\"frequencyHz\":85.0,\"tensionN\":160.0,\"passed\":true,\"sampleCount\":1,\"stdDev\":0,\"ci95Lower\":160,\"ci95Upper\":160,\"comment\":\"curlテスト\"}"
```

`XXXXXXXX` は自分のデプロイ URL に置き換えてください。`{"status":"ok"}` が返れば正常です。

## セキュリティに関する注意

- ウェブアプリ URL を知っている人は、誰でも POST でデータを送信できます（「アクセス: 全員」設定のため）
- URL は社内の関係者のみに共有してください
- スクリプトは **デプロイした Google アカウントのマイドライブ** にデータを保存します
- より厳密な認証が必要な場合は、API キーやトークン検証の追加を検討してください（現行スクリプトには未実装）
